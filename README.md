# CYBERSTER NetSec Internship Portfolio

Welcome to my Network Security engineering portfolio. This repository documents my 12-week progression through the CYBERSTER NetSec Internship, transforming theoretical networking concepts into enterprise-grade Cisco Packet Tracer deployments.

## 🚀 Core Technologies & Protocols
* **Switching:** VLANs, 802.1Q Trunking, STP, LACP EtherChannel, Port Security
* **Routing:** Static Routing, Single-Area OSPF, Router-on-a-Stick (ROAS), Inter-VLAN Routing
* **High Availability:** HSRP (Hot Standby Router Protocol)
* **Security & Services:** Extended Access Control Lists (ACLs), NAT/PAT, DHCP, SSH-only management

---

## 📂 Internship Modules

### 🔹 Phase 1: Network Foundations (Weeks 1-4)
* **Week 1 - OSI Model Threat Analysis:** Deep dive into webpage retrieval workflows and theoretical threat modeling across the OSI layers.
* **Week 2 - Physical Media Deployment:** Logical infrastructure design utilizing T568B cabling standards, RJ45 crimping concepts, and wireless module integration.
* **Week 3 - Layer 2 Lab Network:** Implementation of VLAN segmentation, MAC address table analysis, and edge Port Security to validate Layer 2 boundaries.
* **Week 4 - Hierarchical Design:** Blueprinting a scalable Three-Tier Hierarchical Network Design (Core, Distribution, Access).

### 🔹 Phase 2: Routing & Enterprise Architecture (Weeks 5-8)
* **Week 5 - Dynamic Routing:** Deployment of enterprise-level network architectures utilizing dynamic routing protocols.
* **Week 6 - TechNova Solutions Mid-Term:** Comprehensive mid-term architectural build featuring custom VLSM subnetting, static routing configurations, and initial ACL implementations.
* **Week 8 - Advanced Switching:** Practical execution of inter-VLAN routing concepts and inter-departmental reachability.

### 🔹 Phase 3: Advanced Deployments
* **ECHOBRIDGE Hackathon:** Applied network security simulation, rapid troubleshooting, and threat mitigation.
* **Final Capstone Project - Secure Enterprise Network:** A massive, end-to-end deployment of a medium-sized enterprise network. Features include VLSM IP addressing across 6 dedicated VLANs, ROAS, LACP bandwidth aggregation, HSRP gateway failover, DHCP deployment, NAT/PAT boundary translation, and Extended ACLs for strict Guest isolation.

---

## 🛠️ How to Use This Repository
Each module folder contains the relevant **Cisco Packet Tracer (`.pkt`)** lab files, detailed architectural reports (`.pdf`/`.docx`), and step-by-step verification screenshots. You will need Cisco Packet Tracer installed to interact with the `.pkt` topologies and view the live routing tables.
